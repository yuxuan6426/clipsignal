# 工作流

ClipSignal 总控在 Windows 上的 Codex 工作区运行。剪辑和找客可以独立执行，或用同一个任务关联企业资料、买家画像、活动目标、产物和回执。[双链流程图](workflow.html)

## 内容制作与发布

1. 提供行业、受众、时长、语言、行动目标和获准素材。可选搜集同业参考，记录开场、卖点、证明镜头、节奏、字幕及对应时码。需要用获准的网络片段时，通过已配套的媒体 Skill 和解析站获取、裁切，并保留原始链接和使用范围。
2. 将参考拆解转成自己的拍摄脚本和镜头清单，写明样品、场地、景别、话术及补拍要求。录制说明交付 Markdown，获准时也可由 Gmail 发送纯文本。素材与时码可通过 JSON 回查。
3. 企业在自家工厂或自有展台录制。用火山引擎 Agent Plan 对原片做转写、画面理解与时间定位，再编排时轴。豆包 TTS 2.0 默认女声用于旁白，本地生成原创纯音乐，字幕、旁白和配乐独立保留。过渡页优先用 Chrome 中的 ChatGPT，符合素材验收条件时可用 Codex ImageGen，记录实际来源。
4. 交付可编辑剪映草稿、字幕、预览及素材来源。原生读回、实际草稿根登记、首页可见与成片导出分开核对。成片经审核且目标账号获准时发布，记作品链接、时间和可见性。

## 买家发现与核验

1. 按目标地区、品类、企业角色和关键词，用博查发现入口。连接的 Chrome 读取 X、Facebook、YouTube 的可见帖子、视频、互动、评论及作者主页，记录从内容到企业的路径。
2. 纯文本保留原文出处与时间。视频分析音频、画面和时码，混合内容关联原帖与媒体证据。按事件 ID 和已核实的企业域名去重。回查官网或官方名录，独立记录产品匹配、企业角色、进口能力和主动需求。
3. 按终端、渠道、非终端和待核分流。对明确且获准跟进的询盘整理补问与交接卡。交付可追溯 JSON、Markdown 报告和候选表，保留观察时间、来源及待核项。

视频号通过随包的独立工作台和 MCP 读取作品、可见评论以及已有授权和记录支持的账号关联。获得的候选沿用同一套企业核验和交接字段。后续验收覆盖从评论到企业候选的完整自动获客流程。[^acceptance]

## 邀约与销售接手

经任务授权核对收件人或号码、业务语言和邀约事项。Gmail 用于邮件，电话销售和外呼由云蝠智能的 VoiceAgent 提供，使用接收方配置的语音智能体和线路。Windows 上的 Codex MCP 接入由 yuxuan6426 构建并提供接入支持。ClipSignal 关联发送、收件、接通、回复、预约与到访回执，并交给负责跟进的人。[服务来源与 Windows 接入](setup.md#云蝠智能外呼接入)

冠英首发场景中，买家可受邀到展位见面或参观湖州工厂。销售接手鼓式刹车片询盘时，先问当前车桥、旧件号或样件，再补数量和交付条件、回查目录原页。适配和正式报价由冠英确认。买家的常见问题可用于下一轮内容选题。

## 首次配置、修复与复用

一条提示词加载项目入口并执行环境预检。兼容依赖原位复用，媒体、剪映和视频号按模块准备独立环境。Chrome 文件访问、剪映原生读回、Gmail、Agent Plan、博查和云蝠按任务所需分别验收。

总控从失败环节的输入、产物及回执定位原因，本地证据不足时通过博查或 GitHub 回查对应版本的资料。先确认外部动作状态，再修复、复验并从检查点续跑。任务通过时收录可复用的经验、条件与来源，下次启动时自动查阅工作区内的项目记忆。

## 验收范围

已验证的冠英实证覆盖双语草稿首页人工确认、X 与 Facebook 的同一渠道企业核验和去重，以及用合成 RFQ 验证接手。Gmail 自验发送、云蝠知识库读回、视频号 MCP 作品与评论读取分别留证。展会实跑以成片发布、邮件收件、外呼接通与到访的真实回执验收。闲时持续巡看、展馆周边定向推广和视频号自动获客全链属于后续扩展。[^acceptance]
