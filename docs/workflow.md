# 工作流

用 Clipsignal 总控关联企业、活动目标、内容、线索、交接和回执。内容链与获客链可以独立运行。

- 内容输入参考作品、授权素材、受众和行动引导。拆解、录制说明、素材理解、时间轴、音画合成、原生读回、首页登记、正式导出和发布各有验收。
- 找客输入市场、品类、角色和关键词。博查发现入口，Chrome 阅读 X、Facebook、YouTube 的页面和可见评论，官网核实企业。保存 JSON、候选表及报告。视频号工作台按独立 MCP 运行。
- Gmail 和云蝠使用授权账户，区分准备、执行、发送／通话回执、预约和接手。状态不明先核对服务商。
- 总控负责首次检查、缺项分流、回滚与续跑、验后记忆。查看[双链流程图](workflow.html)。
