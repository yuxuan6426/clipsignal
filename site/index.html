两项交付，供冠英团队接手

全自动剪辑

给 Agent 一条参考视频，或让它自己找对标作品。它用工作区已有的授权素材剪出对标视频，交付可编辑的剪映草稿和预览。

素材不够时，Agent 按授权发邮件列出要补拍的镜头，素材回传后再接着剪。

查看全自动剪辑流程 →

自主获客

Agent 按买家画像查看视频号、Facebook、X 等渠道的作品和评论，核对评论者主页和企业资料，筛出值得联系的买家。

私信邀约与联系方式确认列入展会验证。买家愿意留下商务联系方式后，再按授权用 Gmail 发邮件或用云蝠智能打电话。
