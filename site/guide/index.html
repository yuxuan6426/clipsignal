剪映制作链

从对标拆解到工厂或展台拍摄，再把授权原片制作为带字幕、音轨和来源记录的剪映草稿。

展开选题、录制与成片步骤
  1. 按行业、受众和行动目标搜集参考，标注开场、卖点、证明镜头、节奏与时码。需要取用获准的网络片段时，通过解析站获取并按时间段裁切，登记来源。
  2. 生成 Markdown 录制说明，列出样品、景别、话术和补拍要求。授权时可经 Gmail 发送纯文本说明。
  3. 用 Agent Plan 分析授权原片的音频、画面和时码，编排字幕与时间轴。豆包 TTS 2.0 默认女声用于旁白，本地生成原创纯音乐并保留独立音轨。过渡页优先用已连接 Chrome 中的 ChatGPT，备选为 Codex ImageGen，均需记录来源。
  4. 分别核对原生读回、首页登记和正式导出。成片审核后按账号与平台授权发布，保存作品链接、时间和可见性。

海外企业核验链

博查找入口，连接的 Chrome 阅读 X、Facebook、YouTube 的可见内容、评论与作者主页，再回查官网或官方名录。

展开找客、核验与交付步骤
  1. 输入地区、产品、目标角色和关键词。以冠英为例，可围绕重型商用车售后件筛查批发商、经销商、车桥厂和其他采购企业。
  2. 纯文本记录出处和时间，视频结合音频、画面与时码分析，混合内容关联原帖和媒体。按作品、评论、作者主页、企业官网的顺序保留出处。
  3. 按事件和已核企业域名去重，区分终端、渠道、同业和待核。把产品匹配、进口能力和主动需求分别记证据。明确且获准的询盘附销售交接卡。
  4. 交付结构化 JSON、Markdown 报告与候选表。企业公开商务联系入口、核验时间和下一步均随候选交接。

发布与触达回执

冠英确认对象、账号与邀约内容后安排 Gmail 或云蝠执行。登记发送、接通、回复、展位或湖州访厂预约及实际到访，按接手人和待办交接。

候选证据与销售补问

例如，买家询问鼓式刹车片时，销售补问当前车桥、旧件号或样件，再核对数量、交付条件和目录原页。适配和正式报价由冠英确认。

展会全景

同一展会任务串起素材、买家、邀约与跟进。买家常问的型号和适配问题可以回到下一轮选题。

视频号工作台与 MCP

独立工作台把公开分享预览或授权导入存入本机 SQLite。作品与评论读取已通过验证。按记录核对已关联的公开账号和作品，再交给企业核验链。自动获客全链列入后续验收。

拍摄素材结构

素材清单记录原片、切点、授权和使用位置，剪辑同事可以从草稿回查到原片。

总控与模块

Codex 从同一入口选择剪辑、找客或组合运行，并用任务和回执关联各环节。

首次装载与依赖

新 Windows 设备先在 Codex 预检。兼容软件原位复用，按模块建独立环境，再分别验证剪映、Chrome、Gmail 和业务服务。

自修复与项目记忆

遇到故障先查原步骤和服务回执，必要时用博查和 GitHub 查上游文档。修复后重验原环节，通过再续跑。下次任务可以复用有回执和适用条件的做法。

复跑与证据

  • 已验证　冠英 22 秒剪映草稿首页人工确认。X 与 Facebook 线索回查官网后合并为同一渠道候选。另有合成询盘交接、Gmail 自验发送、云蝠知识库读回和视频号 MCP 作品及评论读取。
  • 展会实跑验收　分别核对成片发布、邮件收件、外呼接通与实际到访。合成样例可用于复跑交接规则。
  • 后续扩展　闲时持续巡看、展馆周边定向推广和视频号自动获客全链。
