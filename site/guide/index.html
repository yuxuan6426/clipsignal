剪映制作链

从对标拆解到工厂或展台拍摄，再把授权原片制作为带字幕、音轨和来源记录的剪映草稿。

展开选题、录制与成片步骤
  1. 用户给出参考链接，或让 Agent 按行业、受众和行动目标找热门参考。拆解开场、卖点、证明镜头、字幕、节奏和时码。需要取用获准的网络片段时，通过解析站获取并按时间段裁切，登记来源。
  2. 盘点工作区里的授权原片，把片段映射到对标结构。素材齐全时直接进入剪辑。缺镜头时生成 Markdown 补拍清单，按授权经 Gmail 发给拍摄同事，注明样品、景别和话术，收到补拍素材后续剪。
  3. 用 Agent Plan 分析授权原片的音频、画面和时码，编排字幕与时间轴。豆包 TTS 2.0 默认女声用于旁白，本地生成原创纯音乐并保留独立音轨。过渡页优先用已连接 Chrome 中的 ChatGPT。Codex ImageGen 备选需接入资产来源校验，再登记来源。
  4. 分别核对原生读回、首页登记和正式导出。成片审核后按账号与平台授权发布，保存作品链接、时间和可见性。

海外企业核验链

博查找入口，连接的 Chrome 查看 X、Facebook、YouTube 等已接入渠道的公开内容、评论和作者主页。视频号作品与可见评论走自研工作台和 MCP。

展开找客、核验与交付步骤
  1. 输入地区、产品、目标角色和关键词，可选巡览行业近期动态。冠英可围绕重型商用车售后件筛查批发商、经销商、车桥厂和其他采购企业。
  2. 纯文本记录出处和时间，视频结合音频、画面与时码分析，混合内容关联原帖和媒体。按作品、评论、作者主页、企业官网的顺序保留出处。
  3. 按事件和已核企业域名去重，区分终端、渠道、同业和待核。把产品匹配、进口能力和主动需求分别记证据。明确且获准的询盘附销售交接卡。
  4. 交付结构化 JSON、Markdown 报告与候选表，保留核验时间和下一步。符合画像且获准触达的候选，转到私信和后续跟进。

私信、邮件与电话跟进

邮件通过 Gmail 发送，电话由云蝠智能 VoiceAgent 拨打。从自动私信到邮件或电话跟进，按平台权限和业务授权验证。

展开私信、联系方式与跟进
  1. 账号、平台和任务授权均允许时，对符合画像的对象发站内私信，介绍相关品类和展会场景，请对方自愿提供商务邮箱或电话。
  2. 记录对方回复、联系方式的来源和同意范围。获准后按所留方式跟进，电话邀约使用已配置的语音智能体和线路。
  3. 按同一任务记录私信及邮件发送、回复、接通、展位或工厂预约与实际到访，交给销售负责后续。

候选证据与销售补问

例如，买家询问鼓式刹车片时，销售补问当前车桥、旧件号或样件，再核对数量、交付条件和目录原页。适配和正式报价由冠英确认。

展会全景

同一展会任务串起素材、买家、邀约与跟进。买家常问的型号和适配问题可以回到下一轮选题。

视频号工作台与 MCP

独立工作台把公开分享预览或授权导入存入本机 SQLite。作品与评论读取已通过验证。按记录核对已关联的公开账号和作品，再交给企业核验链。自动获客全链列入后续验收。

工作台与 MCP 随套件开源，可按模块独立配置。

拍摄素材结构

素材清单记录原片、切点、授权和使用位置，剪辑同事可以从草稿回查到原片。

总控与模块

在 Codex 提供企业资料、买家画像与展会目标，用同一任务标识关联内容、候选、邀约和回执。

首次装载与依赖

新 Windows 设备先在 Codex 预检，按需配置 Git Bash、PowerShell 7、Miniconda、Node.js、Chrome、剪映和 Dev-C++／GCC。按模块检查隔离环境、插件与业务服务。

自修复与项目记忆

Agent 开始任务时查阅以前验证过的做法。遇到故障先检查任务记录，再按需用博查或 GitHub 查官方文档。修复后重试出错的步骤，通过后继续。发送或发布结果待确认时，先查询服务端记录。

展会安排

展前

选定主推型号，在工厂拍产品与生产现场，做成双语预览和剪映草稿。按品类、角色和进口证据整理第一批买家候选。

展中

在自有展台补拍，审核成片后按授权发布。向获准跟进的买家发送邮件，或通过云蝠智能 VoiceAgent电话邀约，预约展位见面或湖州工厂参观。

展后

分别记录邮件已发送、电话已接通、客户回复、已预约与实际到访。销售接手补问和跟进，买家常问的型号用于下一轮选题。

七项能力与实证

以下列出七项能力的验证结果。正式发布、邮件收件、通话和到访分别在实际展会场景核对。

查看七项已验证结果与待验环节
  • 总控与首次配置　在开发设备上用 GCC 编译并运行了 Windows x64 测试程序。接收方设备的首次安装待验。
  • 内容理解与拍摄说明　Agent Plan 已处理冠英原片和访谈录音，一条展会参考片已从拆解串到草稿。自动选样、盘点素材、缺片发补拍邮件和回传续剪的整链待验。
  • 剪映制片　冠英 22 秒双语草稿已通过读取验证，并在剪映首页人工确认可见。编辑器播放、正式导出，以及配音、配乐和过渡页合成的完整复跑待验。
  • 海外线索发现与核验　X 与 Facebook 合并为一条品类和角色已核的渠道候选，进口能力和采购需求待核。已用 YouTube 回放验证浏览入口，并用示例询盘验证销售交接。
  • 展会发布与触达　Gmail 测试邮件已发送，Codex 已通过 MCP 读取云蝠测试知识库。后续验证自动私信与商务联系方式确认、邮件送达、语音智能体及线路、实际外呼和企业账号发布。
  • 自研视频号扩展　已验证导入公开视频号作品、读取微信窗口内的可见评论，以及从 Codex 调用 MCP。按买家画像自动发现并核验企业的完整流程待验。
  • 自进化与自修复　在独立测试环境里完成故障修复并继续任务。另一次运行成功复用了保存的处理办法，模拟邮件保留为待确认。

后续扩展　定时跟踪行业内容、展馆周边定向推广，以及从视频号发现买家到跟进的完整自动流程。
