产品定位

把展会内容和海外买家接起来

ClipSignal — 面向外贸团队的融媒体获客技能套件

  • 剪映草稿与补拍清单
  • 买家候选与销售交接

对外贸团队来说，一条短视频可以介绍产品，评论也可能提供采购信号。

ClipSignal 把这两件事放进同一个展会任务。

团队收到可编辑的剪映草稿，以及能回查的买家候选。

首发企业 · 浙江冠英

让买家在展会找到冠英

首发适配 2026 上海法兰克福汽配展。面向商用车刹车片的进口商、批发商和车桥厂。

  • 12 月 2–5 日
  • 上海国家会展中心
  • 冠英展位 1.1N59

冠英做的是商用车刹车片。

一次具体任务，是让合适的进口商、批发商和车桥厂在上海展会看到产品。

有兴趣的买家可以在展位见面，也可以把湖州访厂排进行程。

交付一 · 全自动剪辑

参考给 Agent，草稿交给团队

你选参考，也可以让 Agent 根据行业选题找对标。它用企业授权实拍生成草稿，缺镜头就出补拍清单。

  1. 拆解参考开场、卖点、证明镜头、字幕和行动引导
  2. 组织素材Agent Plan 理解原片音频、镜头和时码，缺片段按授权用 Gmail 发补拍说明
  3. 交付剪映组织双语字幕、豆包旁白、原创配乐和过渡页，保留可编辑时间轴

剪映草稿示意

实拍工厂实拍产品近景展位
字幕中英双语字幕邀约
音频旁白原创配乐

22 秒双语草稿已原生读回，并人工确认在剪映首页可见。

团队可以指定一条参考，也可以让 Agent 先查找行业视频。

它拆解开场、卖点、证明镜头和节奏，再从工作区的授权实拍里找可用素材。

缺少产品近景一类的镜头时，按授权经 Gmail 发出补拍说明，拿到素材继续剪。

Agent Plan 分析音频、画面和时码，旁白、字幕、原创配乐各保留轨道。

冠英的二十二秒双语草稿已经读回，也确认在剪映首页可见。

交付二 · 自主获客

一条采购信号，一张企业证据卡

博查找站外入口，Chrome 上看 X、Facebook 和 YouTube 的作品、评论及作者主页。视频号由自研 MCP 接入。

  1. 找信号明确地区、品类、企业角色和关键词
  2. 查企业回到官网或官方名录，核对品类、角色、进口能力和主动需求
  3. 交接销售去重后输出候选表、Markdown、JSON 与下一步，附来源和观察时间

先把地区、品类和买家角色设清楚。

博查负责找入口，Chrome 在公开页面看作品、评论和作者主页。视频号用自研 MCP。

例如有人评论正在找重卡制动件供货商，Agent 会回到企业官网核对品类和经销角色。

采购需求与进口能力分别记录。评论可以提供信号，确认采购需要进一步的证据。

销售接手的是一份去重后的候选表，能回查来源、观察时间和待核项。

  2. 邀约回执邮件、通话、回复与预约状态
  3. 下一步展位见面、访厂或补问

视频号工作台把公开作品、可见评论和已关联账号带进同一套核验流程。

遇到获准跟进的买家，按平台权限给对方发私信，确认商务联系方式。

邮件走 Gmail。电话由云蝠智能拨打，Windows 上的 Codex 接入已开源。

把回复、预约和下一步交给销售，销售知道怎样继续。

业务链路 · 展前到展后

让材料、线索和邀约用同一个任务

同一份企业资料、买家画像和活动目标，贯穿两条工作流。

  1. 展前工厂实拍、制作剪映草稿、建立买家候选表
  2. 展中在自有展台补拍，审核后发布，跟进展位会面或湖州访厂
  3. 展后按回执移交有效询盘，把反复出现的买家问题带回下一轮选题

展前在工厂拍素材，同时核验目标买家。

展中补拍、审核发布，按授权跟进展位会面或湖州访厂。

展后销售接手有效询盘，内容团队把客户反复问的问题带回下一轮选题。
