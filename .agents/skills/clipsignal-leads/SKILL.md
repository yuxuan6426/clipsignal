# clipsignal-leads

以市场、品类、企业角色和关键词开工。按专业需求调用 bocha-web-search 获取线索入口；X、Facebook、YouTube 的帖子、互动、评论作者与企业主页通过连接的 Chrome 操作。记录来源、时区与实际可见性，必要时用 `clipsignal-media` 理解媒体。官网或官方名录确认品类、角色、进口能力与主动需求；职位或社媒互动单列待核。使用企业公开商务联系入口。运行 `node tools/leads.mjs <events.json>` 去重和分流，交付 JSON、候选表与报告。只有获准跟进的主动需求生成销售补问和交接卡。
