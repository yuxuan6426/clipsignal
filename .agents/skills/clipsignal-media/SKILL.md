# clipsignal-media

提供参考作品、受众、行业、时长、授权与内容目标。通过宿主 Chrome查看可见原页；需要下载的合法可用片段通过上游 douyin-agent 的解析站链路取得。复用其 Agent Plan 能力记录音频转写、原帧时序和来源。纯文本独立处理，混合页关联帖子与媒体证据。提取开头、卖点、证明镜头、节奏、字幕和行动引导，生成 Markdown 拍摄清单及 JSON 来源时码。给工作人员写明场地、镜头、景别和素材回传要求。授权时经 Gmail 寄出纯文本并保存回执。
